As the description of the repository says, 
This is a project which total comprises ~60 loops which are implemented using python *for* loops

The repository has an MIT License with a folder named Art.
/Art includes the following.
 - /1 - It has 20 loops in the difficulty level 1
 - /2 - It has 23 loops in the difficulty level 2
 - /3 - It has 15 loops in the difficulty level 3

Here 1 is the easiest and 3 is the hardest.

_How can this be helpful_
Well, It might not be helpful for an experienced progrmamer.
It can definitely help out a beginner.
----
Recommended Learning Procedure.
1. Use an AI tool to generate pattern blocks and try to implement them in the way you would like.
2. Use the current repository as a reference or a library of such loops.
3. Make your own version of this repository.

*_How to clone the repository_*
1. bash'git clone https://github.com/CuriousDudeDev/ForArt'
2. cd ForArt
